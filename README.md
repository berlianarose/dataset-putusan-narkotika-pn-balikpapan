# Dataset Putusan Perkara Narkotika

## Deskripsi
Dataset ini merupakan kumpulan dokumen putusan perkara pidana khusus dengan klasifikasi Narkotika dan Psikotropika yang diperoleh secara manual melalui Direktori Putusan Mahkamah Agung Republik Indonesia.

## Sumber Data
- Sumber: [Direktori Putusan Mahkamah Agung](https://putusan3.mahkamahagung.go.id/direktori.html)
- Lembaga peradilan: Pengadilan Negeri Balikpapan
- Klasifikasi: Narkotika dan Psikotropika
- Jenis perkara: Pidana Khusus

## Isi Dataset
Dataset terdiri dari 5 dokumen PDF putusan pengadilan.

Informasi metadata setiap dokumen disajikan dalam file `Overview.xlsx`, meliputi:
- Nomor putusan
- Lembaga peradilan
- Barang bukti
- Amar putusan

## Struktur Folder
- `Dataset/` : berisi dokumen PDF putusan.
- `Narkotika.zip` : arsip berisi dokumen PDF.
- `Overview.xlsx` : metadata dan ringkasan setiap putusan.
- `README.md` : dokumentasi dataset.

## Tujuan
Dataset ini digunakan untuk memenuhi tugas mata kuliah Information Retrieval, khususnya pengumpulan dataset dokumen hukum sebagai bahan untuk proses crawling, preprocessing, dan indexing.

## Catatan
Data dikumpulkan untuk keperluan akademik. Informasi dalam dokumen merujuk pada putusan yang diterbitkan melalui Direktori Putusan Mahkamah Agung Republik Indonesia.
